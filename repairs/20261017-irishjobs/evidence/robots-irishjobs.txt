# Lectura para la reparación (interpretación, no parte del fichero original):
# - El grupo `User-agent: *` NO veta `/jobs/` en bloque (a diferencia de los
#   grupos de bots con nombre, que sí tienen `Disallow: /`).
# - La SERP `/jobs/<rol>?age=7` y el detalle `/job/<slug>-job<id>` no casan con
#   ningún `Disallow` del grupo `*` -> permitidos.
# - `Disallow: /*?action=` y `/*&action=` vetan la URL de paginación que
#   construye hoy el scraper (`?page=2&action=paging_next&age=7`).
# - `Disallow: /*&page=` veta un parámetro `page` precedido de `&`; el enlace
#   propio del sitio es `?page=N&ag=7` (page como primer parámetro) -> permitido.
# - `Disallow: /JobSearch/*/api/` y `/jobsearch/*/api/` vetan APIs internas de
#   búsqueda si existieran.
# ---------------------------------------------------------------------------
